Project Overview

VoxelForge is a robotic machine designed to recreate Minecraft structures in the real world. Users construct a model inside our custom-built web application before sending the design wirelessly to the machine.

The web application was inspired by Minecraft itself and features textured inventory icons, an immersive interface, and a dynamic day-night cycle.

The printer uses an ESP32-based control system with a three-axis gantry and a servo-powered claw to place blocks according to the generated build instructions.

Development Process

Software Development

Developed the VoxelForge web application with a Minecraft-inspired interface, inventory system, textured blocks, and a dynamic day-night cycle.

Machine Construction

Designed and assembled a laser-cut frame with a three-axis gantry and servo-operated claw.

Electronics

Integrated stepper motors, drivers, power supplies, sensors, and an ESP32-based control system.

Communication

When GPIO limitations became an issue, the architecture was redesigned around two ESP32 boards communicating through WebSockets.

Testing & Debugging

Extensively tested motion, electronics, communication, and mechanical systems while solving hardware failures throughout development.

06

Challenges

Loose Wiring

Intermittent electrical connections repeatedly halted testing.

Short Circuits

Several ESP32 boards were damaged during rapid prototyping.

Power Supply

The Z-axis driver required more reliable power than our initial design provided.

GPIO Limit

The original ESP32 ran out of available pins for additional hardware.

Servo Current

The servo consumed enough current to destabilize the controller during testing.

Motor Drivers

Multiple motor drivers overheated and failed during debugging.

07

Assignment Requirements

Motor Calibration

Limit switches were added to establish a repeatable home position, but full calibration was not completed before the project deadline due to hardware issues.

Circle Precision

Because the machine was not fully operational, we were unable to complete the required circle drawing and percent error analysis.

08

Reflection & Future Work

VoxelForge was an ambitious project for a single week and required software engineering, electronics, mechanical design, and embedded systems development simultaneously.

Although the printer was not completed before the deadline, our team established the complete software pipeline, communication architecture, and mechanical platform.

I plan to continue developing VoxelForge as part of my final project and prepare it for the Digital Fabrication Project Fair. With additional time, the remaining work will focus on improving electrical reliability, completing machine calibration, and enabling fully autonomous Minecraft structure fabrication.
